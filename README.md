# CHƯƠNG 1: TỔNG QUAN VỀ ĐỀ TÀI

| STT | Mục | Nội dung cần làm |
|---:|---|---|
| 1.1 | **Giới thiệu đề tài** | Giới thiệu CampusMatch, bối cảnh kết nối sinh viên trong môi trường đại học |
| 1.2 | **Lý do chọn đề tài** | Nhu cầu kết nối; hạn chế của các nền tảng hiện tại; vấn đề xác thực sinh viên; nhu cầu tìm bạn cùng trường/ngành/sở thích |
| 1.3 | **Mục tiêu đề tài** | Các mục tiêu cần đạt được của CampusMatch |
| 1.4 | **Phạm vi đề tài** | Phạm vi chức năng và phạm vi đối tượng |
| 1.4.1 | Phạm vi chức năng | Tài khoản, hồ sơ, Matching, Chat, Block/Report, quản trị |
| 1.4.2 | Phạm vi đối tượng | Khách, Sinh viên, Quản trị viên |
| 1.5 | **Đối tượng sử dụng hệ thống** | Mô tả các tác nhân |
| 1.5.1 | Khách | Người chưa đăng nhập; Đăng ký, Đăng nhập |
| 1.5.2 | Sinh viên | Người đã đăng nhập; sử dụng các chức năng chính |
| 1.5.3 | Quản trị viên | Quản lý người dùng, báo cáo và hệ thống |
| 1.5.4 | Hệ thống bên ngoài | Mail Server, dịch vụ thông báo, lưu trữ ảnh |
| 1.6 | **Ý nghĩa của đề tài** | Ý nghĩa thực tế, học thuật và khả năng ứng dụng |
| 1.7 | **Cấu trúc đồ án** | Giới thiệu nội dung từng chương |

# CHƯƠNG 2: KHẢO SÁT VÀ THU THẬP THÔNG TIN
